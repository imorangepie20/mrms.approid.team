# 개인화 추천 초기 전략 결정

날짜: 2026-09-20

## 결정

초기 추천은 `sentence-transformers/paraphrase-multilingual-mpnet-base-v2`로 트랙 메타데이터를 임베딩하고, 사용자별 취향 벡터를 사용자 액션으로 갱신하는 방식으로 구현한다.

## 이유

- TIDAL 플레이리스트에서 확보 가능한 메타데이터만으로 추천을 시작할 수 있다.
- TIDAL API 접근 권한은 확보된 것으로 본다. 구현 전 실제 응답 필드와 허용 범위는 확인한다.
- 2026-09-21 사용자가 TIDAL Developer Terms의 AI 서비스 제한 제약을 해소했다. 테스트 배포까지는 사용자가 가져온 TIDAL 트랙 메타데이터를 임베딩 모델 입력으로 사용할 수 있다. 근거는 `docs/changes/2026-09-21-tidal-ai-analysis-allowed.md`에 있다.
- 사용자별 거대 모델을 별도 학습하지 않아도 개인화와 즉시 갱신을 제공할 수 있다.
- 사용자별 벡터를 분리해 개인 취향과 행동 데이터를 혼용하지 않는다.

## 동작 원칙

1. 곡명, 아티스트, 앨범, 장르 등 실제로 제공되는 메타데이터를 정규화해 트랙 임베딩을 만든다.
2. 사용자의 플레이리스트 트랙으로 초기 취향 벡터를 만든다.
3. 좋아요, 저장, 완청, 스킵, 관심 없음 등 정의된 사용자 액션에 가중치를 부여해 해당 사용자 벡터만 갱신한다.
4. 사용자 벡터와 가까운 미청취 트랙을 후보로 삼고, 중복·다양성 규칙을 적용해 최종 추천을 만든다.
5. 사용자가 좋아하지 않음으로 확정한 트랙은 해당 사용자의 이후 추천 후보에서 영구 제외한다.

## 보류한 선택지

- `laion/larger_clap_music`: TIDAL 오디오 프리뷰를 적법하게 이용할 수 있는지와 처리 비용을 확인한 뒤 검토한다.
- Two-Tower 추천 모델: 충분한 사용자 행동 로그와 TIDAL 카탈로그 학습 데이터를 확보한 뒤 자체 학습으로 고도화한다.
- `m-a-p/MERT-v1-95M`: 모델 라이선스가 상용 서비스 요구와 맞는지 별도 검토 전에는 사용하지 않는다.

## 미정 항목

- TIDAL API의 실제 메타데이터 필드와 인증·권한 범위
- 사용자 액션의 종류, 가중치, 취소·되돌리기 규칙
- 취향 벡터의 저장·삭제·버전 관리 정책
- 추천 품질의 측정 지표와 성공 기준
