# 관리자 템플릿 런타임 결정

날짜: 2026-09-20

## 결정

관리자 프런트엔드는 `C:\Wspace\hud-admin-template`을 복사해 사용하는 React + Vite + TypeScript + Tailwind CSS 기반으로 시작한다.

## 이유

- 제공 템플릿이 이미 React 18, Vite, TypeScript, Tailwind CSS와 관리자 레이아웃·대시보드·테마 구조를 포함한다.
- 현재 `music-pie`에는 제품 프런트엔드 코드가 없으므로, Next.js로 먼저 이식하는 것보다 템플릿을 보존하는 편이 구현 범위와 시각적 차이를 줄인다.
- 관리자 테마를 새로 설계하거나 다른 디자인 시스템으로 교체하지 않는다.

## 영향

- 관리자 UI의 빌드·개발 명령은 템플릿의 Vite 구성을 기준으로 확인한다.
- 템플릿의 공용 레이아웃, 사이드바, 헤더, Tailwind 토큰을 재사용한다.
- 음악 추천 도메인의 관리자 화면을 추가할 때도 기존 템플릿의 컴포넌트와 상호작용 패턴을 우선 사용한다.

## 제외 범위

- 사용자용 서비스 화면의 프런트엔드 기술 선택은 이 결정에 포함하지 않는다.
- Next.js 도입 또는 Vite 관리자 화면의 Next.js 이식은 별도 요구와 계획이 있을 때 검토한다.
