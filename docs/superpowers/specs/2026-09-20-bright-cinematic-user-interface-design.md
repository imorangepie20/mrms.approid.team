# 밝은 시네마틱 사용자 인터페이스 디자인

## 목적

Music Pie의 사용자 웹을 고급스럽고 단순하지만 몰입감 있는 음악 발견 경험으로 정한다. 관리자는 제공된 `hud-admin-template`을 유지하며 이 명세 범위에 포함하지 않는다.

## 디자인 원칙

- 밝은 오프화이트 바탕과 코발트·스카이 블루를 브랜드 주색으로 사용한다.
- 앨범 아트와 짧은 에디토리얼 메시지로 시선을 이끌되, 최신 음악과 플레이리스트를 풍부하게 제공한다.
- 모든 주요 화면에서 재생을 시작할 수 있고, 고정 플레이어는 경로 전환 뒤에도 유지된다.
- 개인화 기능은 로그인과 TIDAL 온보딩 완료 뒤에만 제공한다.
- EMS 원본 카탈로그, 사용자별 GMS, 사용자별 MMS의 경계를 화면에서도 분명히 드러낸다.

## 전역 구조

### 내비게이션

- 전역 메뉴는 `홈 / EMS / GMS / MMS / 검색`으로 구성한다.
- 데스크톱은 상단 내비게이션을 사용한다.
- 모바일은 동일한 정보 구조를 하단 내비게이션으로 제공한다.
- 모바일 하단 내비게이션과 고정 플레이어는 동시에 표시될 때도 스크롤 콘텐츠의 마지막 항목을 가리지 않도록 하단 안전 여백을 확보한다.

### 색상과 표현

- 기본 표면: 오프화이트와 매우 연한 블루 그레이.
- 핵심 행동과 선택 상태: 코발트 블루.
- 보조 강조와 앨범 아트 배경: 스카이 블루 계열.
- 히어로 영역: 코발트에서 스카이로 이어지는 시네마틱 그라데이션과 앨범 아트 조합.
- 본문은 충분한 명도 대비를 유지하고, 블루는 정보 전달과 행동 유도에만 집중해 사용한다.

## 화면별 디자인

### 홈

- 짧고 강한 시네마틱 히어로를 상단에 둔다. 히어로는 화면을 독점하지 않으며 최신 콘텐츠를 첫 화면에서 바로 볼 수 있게 한다.
- 아래 순서로 가로 스크롤 레일을 배치한다: 최신곡, 최신 플레이리스트, 플랫폼별 플레이리스트, 당신을 위한 추천, 이어 듣기.
- 각 레일은 제목, 짧은 설명, `전체 보기`, 앨범 아트 카드로 구성한다.
- 트랙 카드는 재생과 개인화 저장 진입점을 제공한다. 게스트가 저장을 시도하면 TIDAL 온보딩 안내를 연다.

### EMS

- EMS는 외부 음악 카탈로그를 탐색하는 독립 화면이다.
- 상단에 검색과 장르·무드·플랫폼 필터를 둔다.
- 트랙, 앨범, 플레이리스트를 빠르게 전환해 탐색할 수 있게 한다.
- EMS의 재생과 공개 탐색은 게스트에게도 제공한다. 개인화 행동은 로그인 안내로 전환한다.

### GMS

- GMS는 여러 추천을 빠르게 비교·판단하는 반응형 카드 그리드다.
- 데스크톱은 화면 폭에 따라 2~4열, 모바일은 한 열 카드 목록을 사용한다.
- 카드에는 앨범 아트, 제목, 아티스트, 앨범, 재생, `MMS에 담기`, `다시 추천하지 않기`를 항상 보이게 둔다.
- 영구 제외 전에는 영향 범위를 설명하는 확인 대화상자를 표시한다. 확정 후에는 즉시 되돌리기를 제공한다.
- 제외는 해당 사용자 GMS와 MMS에만 영향을 주며 EMS 원본과 다른 사용자에게 영향을 주지 않는다는 설명을 노출한다.

### MMS

- MMS는 개인 플레이리스트처럼 트랙 목록이 주인 화면이다.
- 데스크톱은 트랙 테이블, 모바일은 컴팩트한 트랙 목록을 사용한다.
- 기본 열 또는 정보 순서는 앨범 아트, 제목, 아티스트, 앨범, 추가일이다.
- 재생, 정렬, 최근 추가 곡은 목록 가까이에 둔다.
- 추천 제외 관리는 보조 영역으로 두며 일반 MMS 목록과 분리한다.

### TIDAL 온보딩

- `TIDAL 연결 → 플레이리스트 선택 → MMS 준비 완료`의 3단계를 명확히 표시한다.
- 빈 선택, 분석할 트랙이 없는 플레이리스트, 연결 실패에는 이유와 재시도 행동을 같은 화면에 제공한다.
- 완료 화면은 MMS 초기화와 GMS 추천 시작을 명시하고 다음 행동으로 연결한다.

### 고정·전체 화면 플레이어

- 고정 플레이어는 밝은 반투명 바에 현재 트랙, 앨범 아트, 이전/재생/다음, 진행 위치를 제공한다.
- 작은 화면에서는 컴팩트한 미니 플레이어로 보이며, 트랙 정보를 누르면 전체 화면 플레이어를 연다.
- 전체 화면 플레이어는 코발트 중심의 앨범 아트, 재생 위치, 큐, 재생 제어를 제공한다.

## 상태와 접근성

- 게스트는 홈과 EMS의 공개 탐색을 이용할 수 있다. GMS, MMS, 저장, 선호 판정에는 로그인과 온보딩을 요구한다.
- 아이콘만 있는 컨트롤에는 접근 가능한 이름을 제공한다.
- 모든 핵심 버튼은 키보드로 조작할 수 있고 뚜렷한 포커스 표시를 제공한다.
- 대화상자는 제목·설명·닫기 동작을 제공하고 Esc로 닫을 수 있어야 한다.
- 반응형 화면에서 카드, 하단 내비게이션, 플레이어, 목록의 겹침이 없어야 한다.

## 검증 기준

- 데스크톱과 모바일에서 전역 메뉴와 고정 플레이어가 콘텐츠를 가리지 않는다.
- 게스트는 EMS를 탐색·재생할 수 있지만 개인화 행동은 온보딩으로 안내된다.
- GMS 수락은 MMS에 반영되고, 제외는 해당 사용자의 추천 후보에서 제거된다.
- MMS는 트랙 목록 중심으로 렌더링되고 제외 관리와 분리된다.
- 재생 트랙과 재생 위치는 경로 전환 뒤에도 유지된다.
- 온보딩의 빈 선택, 트랙 없음, 연결 실패 상태는 이해 가능한 안내와 재시도 행동을 제공한다.
