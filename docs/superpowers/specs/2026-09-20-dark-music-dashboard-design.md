# 다크 음악 대시보드 사용자 UI 설계

## 결정

기존의 밝은 시네마틱 사용자 UI를 폐기하고 `MusicRecommendationApp` 참조 프로젝트의 다크 대시보드 언어를 Music Pie 사용자 화면에 적용한다. 참조 프로젝트의 이미지는 원격 URL을 그대로 쓸 수 있으나, 코드·상태 모델·사용자 데이터는 복사하지 않는다.

## 시각 언어

- 배경 `#08080f`, 카드 `#111119`, 경계 `rgba(255,255,255,.07)`
- 주색 보라 `#8b5cf6`, 보조 포인트 틸 `#00d4c8`
- 데스크톱 고정·접이식 왼쪽 사이드바, 모바일 하단 메뉴
- 큰 가벼운 제목, 작은 모노 데이터 라벨, 어두운 반투명 표면
- 앨범·음악 제작·공연 이미지는 히어로와 카드에 사용하고 텍스트 영역에는 어두운 그라데이션을 겹친다.

## 정보 구조

- 메뉴: 홈, MMS, GMS, EMS와 검색 진입점
- 홈: 이미지 히어로, 가로 트랙/플레이리스트 레일, 공개 탐색 CTA
- EMS: 게스트에게 열린 검색·필터 카탈로그
- GMS: 다중 추천 카드와 좋아요/제외 판단
- MMS: 트랙 목록과 개인 음악 공간
- 플레이어: 사이드바 폭을 고려한 하단 반투명 미니 플레이어

## 확정 레이아웃 기준

- EMS는 넓은 배너 아래 플랫폼 필터 칩, 보기 전환, 트랙 도입 버튼, 앨범·플랫폼·시간 열을 가진 어두운 트랙 테이블을 사용한다.
- GMS는 틸 배너와 상태 수치, 영구 제외 영향 범위를 알리는 안내 바, 가로로 비교하는 추천 트랙 카드로 구성한다.
- 사이드바에는 `My Music Space / MMS`, `Gateway Music Space / GMS`, `External Music Space / EMS`를 두 줄로 표시하고, 현재 공간에는 보라색 강조 표면을 사용한다.
- 페이지 제목 바는 공간의 영문 전체 이름과 약어를 함께 표시한다.

## 보존 규칙

- 게스트는 홈·EMS 재생과 탐색을 사용할 수 있고 개인화 액션은 TIDAL 연결 안내로 보호한다.
- 영구 제외는 해당 사용자 추천 후보에만 반영하며 EMS와 다른 사용자는 영향받지 않는다.
- 실제 TIDAL OAuth, 토큰·개인 데이터 영속 저장은 이번 UI 변경에 추가하지 않는다.
