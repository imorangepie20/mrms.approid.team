# 검색 제시어 외부 클릭 닫기 계획

## 목표

검색이 완료된 뒤에도 제시어 박스를 유지하되, 검색창과 제시어 박스 바깥을 누르면 닫는다.

## 변경

- 검색 컨테이너에 ref를 연결하고 document `pointerdown`으로 외부 클릭을 판정한다.
- 검색창과 제시어 항목 내부 클릭은 박스를 유지하고, 외부 클릭 뒤 검색창을 다시 누르거나 focus하면 기존 제시어를 연다.
- `Escape`로도 박스를 닫는다.
- 카탈로그 검색 성공 시 제시어를 자동으로 비우지 않는다.
- 외부 클릭으로 닫은 현재 요청의 늦은 제시어 응답은 박스를 다시 열지 못하게 한다.
- 새 검색어 입력, 결과 탭 선택, 검색 실패 fallback은 유지한다.

## 완료 기준

- 검색 결과와 제시어 박스가 함께 표시된다.
- 검색창 내부 클릭은 제시어를 유지한다.
- 결과 영역 등 외부 클릭은 제시어를 닫는다.
- 입력창 포커스가 유지된 외부 클릭 뒤에도 검색창을 다시 누르면 제시어가 열리고 `Escape`로 닫힌다.
- focused test, 전체 test, lint, build를 확인하고 커밋·푸시 후 Web만 배포한다.
