# 전체 플레이어 대기열 곡 정보

## 목표·완료 기준

- 전체 플레이어의 대기열 각 행에 제목·아티스트·앨범·앨범 아트·재생 시간을 표시한다.
- 앨범 아트·앨범·재생 시간이 없는 곡도 행과 선택 동작이 유지된다.
- 현재 재생곡 강조와 모바일 한 열 레이아웃을 유지한다.

## 변경·확인

1. `FullPlayerDialog`의 대기열 행에 기존 `Track` 데이터를 표시한다.
2. `full-player.css`에서 정보의 줄임 표시와 좁은 화면 배치를 조정한다.
3. Web build와 diff를 확인하고 운영 Web 이미지를 배포한다.

자동 테스트 추가·실행은 요청 범위에 넣지 않는다.
