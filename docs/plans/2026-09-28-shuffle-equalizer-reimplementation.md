# 셔플 재생·비주얼 이퀄라이저 재구현 계획

## 목표

- 앨범·플레이리스트의 셔플 버튼이 재생 가능한 큐를 한 번에 섞고 첫 곡부터 즉시 재생한다.
- 새 큐를 선택했을 때 이전 셔플 표시와 실제 큐 순서가 어긋나지 않게 한다.
- 전체 플레이어 앨범 아트 하단의 반투명 EQ를 실제 analyser 신호 기반의 중앙 대칭 스펙트럼으로 다시 구현한다.

## 변경

- `MusicSessionProvider`에 큐 생성·셔플·첫 곡 load를 한 연산으로 처리하는 `playQueue`를 추가한다.
- 일반 큐 교체는 셔플 상태를 해제하고, 셔플 재생은 재생 가능한 곡만 대상으로 순서를 바꾼 뒤 셔플 상태를 켠다.
- 동일 순서가 우연히 다시 나오는 경우를 방지해 2곡 이상이면 실제 순서 변화가 보이게 한다.
- MMS와 검색 상세의 전체 재생·셔플을 `playQueue`에 연결한다.
- EQ는 실제 frequency bin을 로그 밴드로 집계한 뒤 저역을 중앙, 고역을 양쪽으로 펼치는 대칭 막대로 그린다. 신호가 없을 때는 최소 기준선만 표시하고 가짜 애니메이션은 만들지 않는다.

## 검증

- provider에서 셔플 큐 생성, 첫 곡 load, 일반 큐 전환 시 셔플 해제를 회귀 테스트한다.
- MMS·검색 상세 셔플 버튼이 `shuffle: true`로 `playQueue`를 호출하는지 확인한다.
- EQ의 밴드 분포, 좌우 대칭, 중앙 정렬과 크기 제한을 단위 테스트한다.
- focused test, 전체 test, lint, build와 desktop·390x844 운영 브라우저 재생·셔플·canvas를 확인한다.
- Web만 교체하며 사용자 데이터, active EMS catalog와 상시 worker를 보존한다.
