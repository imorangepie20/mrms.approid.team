# 멜론 한국대중음악 장르 수집

## 범위와 완료 기준

- 관리자가 멜론 한국대중음악의 장르별 최신곡 수집을 시작·일시정지·재개하고 진행 상태와 최근 원천곡을 확인한다.
- 멜론 곡 ID를 기준으로 곡명·가수·앨범·장르·원본 주소·최초/최근 확인 시각을 중복 없이 저장한다.
- 수집 후보는 기존 TIDAL 확인 경로를 거친 뒤에만 EMS 활성 트랙이 된다. 매칭 성공 시 멜론 출처를 기록한다.
- 장르와 페이지 위치를 저장해 작업을 재개한다. 3초 이상 간격을 두고 조회하며 제한 응답과 차단 신호에서는 멈춘다.
- 입력 URL은 받지 않는다. 수집 대상은 멜론의 한국대중음악 장르 링크와 해당 목록 페이지로 고정한다.

## 변경 순서

1. DB: 멜론 원천곡·장르·작업 표와 EMS 원천/실행 유형 제약 추가. 역방향 마이그레이션 제공.
2. 워커: 장르 링크·페이지 목록 추출, 원천 upsert, 후보 적재, 체크포인트, TIDAL 확인 및 출처 승격.
3. 관리자 API·화면: 상태와 원천 목록 조회, 시작·일시정지·재개, 작업 진행 표시.
4. 검증: Python 구문 확인, Web·관리자 빌드와 lint, 변경 diff 검토. 자동 테스트 추가·실행은 현재 요청 범위에 넣지 않는다.

## 결정 및 제한

- 멜론 목록 메타데이터 보관과 관리자 표시는 사용자가 허용 범위를 확인했다.
- 원천곡 수와 TIDAL 검증 완료 수를 분리해 표시한다.
- 목록에 ISRC·재생시간이 없으므로 TIDAL 제목·가수 외 앨범 일치도 확인한다. 앨범 불일치 또는 다중 후보는 자동 승격하지 않는다.
- 차단 우회·로그인 세션 사용·이미지 복제는 하지 않는다.
