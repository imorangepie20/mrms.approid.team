# 메인 콘텐츠 확장 계획

## 목표

- 메인에서 서비스 개념, 이용 순서, 음악 이야기를 EMS 실데이터 선곡과 비슷한 비중으로 보여준다.
- 관리자는 메인 화면 관리에서 새 영역의 문구, 링크, 순서, 노출을 편집하고 음악 이야기 카드를 추가할 수 있다.
- 관리자 권한과 기존 EMS 화면 설정은 유지한다.

## 순서

1. `017_home_content.sql`: 메인 전용 콘텐츠 테이블과 초기 문구를 만든다. hero·concept·guide는 고정 슬롯, story는 추가 가능하다.
2. Web 공개·관리자 API와 입력 검증: 공개 응답은 활성 콘텐츠만, 관리자 응답은 전체를 반환한다. 링크는 내부 경로만 허용한다.
3. Home 화면: 읽기 쉬운 서비스 소개와 3단계 이용 안내, 음악 이야기, 기존 EMS 선곡 레일을 구성한다. 데이터 오류 시 화면 나머지를 유지한다.
4. 관리자 메인 화면 관리: 콘텐츠 편집과 음악 이야기 추가를 기존 선곡 관리 위에 둔다.
5. 타입·빌드·린트·화면 확인 후 변경 기록. 자동 테스트는 사용자 요청이 없어 추가·실행하지 않는다.

## 완료 기준

- 메인에서 소개·이용법·음악 이야기·실제 EMS 선곡이 보인다.
- 관리자가 문구·링크·순서·노출을 저장하면 공개 화면에 반영된다.
- 관리자 API는 비로그인·일반 회원을 거부한다.
- 작은 화면과 키보드 탐색이 가능하다.
