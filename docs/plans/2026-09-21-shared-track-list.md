# 공통 트랙 목록과 재생

## 목표

검색·EMS·MMS의 트랙 목록을 공통 `TrackList`로 통합하고, 목록에서 선택한 트랙을 전역 플레이어로 즉시 재생한다.

## 구현

- 공통 트랙 행에 번호, 커버, 제목, 아티스트, 앨범, 재생 버튼을 표시한다.
- 재생 시 현재 목록 전체를 큐로 설정한 뒤 선택 트랙을 재생한다.
- 검색과 EMS/MMS의 중복 목록 구현을 공통 컴포넌트로 교체한다.
- GMS 선호 액션 카드는 이번 범위에서 유지한다.
- 전역 플레이어에 셔플, 반복, 볼륨, 음소거, 재생 시간과 대기열 현재 곡 표시를 추가한다.
- 셔플은 현재 곡을 유지하고 나머지 대기열만 섞는다.

## 완료 기준

- 공통 컴포넌트의 큐 설정과 재생 동작 테스트가 통과한다.
- 검색·EMS·MMS에서 동일 목록 컴포넌트를 사용한다.
- 전체 테스트, ESLint, production build가 통과한다.
- 셔플·반복·볼륨 상태가 축소 플레이어와 전체 플레이어에서 공유된다.
