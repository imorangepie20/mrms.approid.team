# GitHub 프로필 위시켓 전체 포트폴리오 반영 계획

## 범위

사용자 요청에 따라 위시켓 `mibeen`의 전체 포트폴리오를 GitHub `imorangepie20` 프로필에 반영한다. 위시켓 공개 목록과 네 상세 페이지를 직접 읽고 기간·참여율·역할·기술·주요 기능·성과·단계를 확인한다. 기존 Music Pie와 B2B 본문은 유지하며 RESM, Alpha Momega 및 필요한 B2B 보완, 네 프로젝트 목록·링크를 추가한다. 확인되지 않은 경력·운영 성과·기술은 추정하지 않는다.

## 순서

1. 위시켓 목록과 상세 네 개 및 저장소 링크 조사.
2. 프로필 README 전체 목록과 누락 프로젝트의 상세 작성, 기존 내용 보존 검증.
3. 사용자 요청에 따라 프로필 저장소에 커밋·push.
4. 원격 원문과 공개 렌더링 검증 및 화면 증거 저장.

## 사전 객관적 완료 기준

- A1: 위시켓 실제 목록 네 항목과 GitHub 프로젝트 목록·상세 섹션을 4/4 대조하고, 각 프로젝트의 역할·기간·기술·기능을 상세 원문 근거에 맞게 작성한다.
- A2: 기존 Music Pie·B2B 본문, 경력·연락처·기존 이미지와 링크를 보존하고 변경 범위가 프로필 문서 및 필요한 프로젝트 화면에 한정된다. `git diff --check` 성공.
- A3: 새 외부 프로젝트/포트폴리오 링크가 조회되고 원격 main SHA와 게시 원문이 local Git blob과 일치한다.
- A4: 공개 GitHub 프로필에서 프로젝트 목록 네 행 및 상세 네 섹션·링크가 표시되고 사용한 이미지가 정상 로드된다. 스크린샷·DOM 검증 기록을 저장한다.
