# 메인 카드 재생 오버레이 복구 계획

## 범위

- Home의 EMS 트랙 카드 재생 오버레이가 hover 조건에 의존하지 않도록 복구한다.
- 재생 버튼이 항상 보이고 클릭 가능한지 회귀 테스트로 고정한다.
- TIDAL 재생 식별자가 실제 Home 응답에 포함되는지 확인한 뒤 UI 변경과 분리한다.

## 변경 순서

1. `TrackCard`의 오버레이·버튼 CSS 조건을 확인하고 실패 테스트를 추가한다.
2. 오버레이를 기본 표시·상호작용 상태로 바꾸고 전용 CSS로 전역 `.cover-play-button` 규칙과 충돌하지 않게 한다.
3. TrackCard/전체 테스트, ESLint, production build를 실행한다.
4. 변경 기록과 현재 개발 상태를 갱신한 뒤 커밋·푸시·Zorin 배포 및 HTTP/health smoke를 확인한다.

## 완료 기준

- 메인 카드에 보라색 재생 오버레이가 기본 표시된다.
- 오버레이 버튼 클릭 시 기존 `onPlay` 경로가 호출된다.
- 기존 좋아요·큐 동작을 깨뜨리지 않는다.
- 테스트·lint·build가 통과하고 배포 release가 health 상태다.
