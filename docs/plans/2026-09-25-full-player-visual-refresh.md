# 전체 플레이어 화면 개선

## 목표·완료 기준

- 전체 플레이어를 열면 현재 곡의 제목·아티스트·앨범·재생 상태가 첫 화면에서 보인다.
- 앨범 아트, 재생 조작부, 대기열을 명확한 박스로 구분한다. 현재 곡의 대기열 행도 강조한다.
- 기존 재생·탐색·좋아요·셔플·반복·볼륨 동작과 접근성 이름을 유지한다.
- 데스크톱 2열과 모바일 1열에서 정보가 잘리거나 조작부가 가려지지 않는다.

## 변경 순서

1. `FullPlayerDialog`의 정보 순서와 박스 구조를 조정한다.
2. 기존 검정·보라 토큰으로 전체 플레이어 전용 스타일을 추가한다.
3. Web build·lint와 실제 브라우저 데스크톱·모바일 표시를 확인한다.

## 범위

- 재생 엔진, 음악 데이터, API, 컴팩트 플레이어는 변경하지 않는다.
