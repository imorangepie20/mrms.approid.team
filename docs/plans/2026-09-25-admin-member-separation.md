# 관리자·일반 회원 접근 분리

## 기준과 완료 조건

- 기존 Auth0 세션을 공통 인증으로 쓰고 `ADMIN_AUTH0_SUBJECTS`를 관리자 권한의 단일 기준으로 유지한다. 관리자도 일반 회원 음악 화면을 사용할 수 있다.
- 비로그인 `/admin/*`은 Auth0 로그인으로 이동하고, 로그인한 일반 회원에게는 관리자 앱 자산을 렌더링하지 않는다. 관리자 API의 기존 `401/403` 경계는 유지한다.
- 일반 회원 화면의 관리자 링크는 관리자에게만 표시한다. 관리자 화면의 프로필·로그아웃은 실제 회원 화면과 Auth0 로그아웃으로 연결하며 템플릿 가짜 로그인은 사용하지 않는다.

## 변경 순서

1. 관리자 권한 판별 함수를 API와 페이지·회원 내비게이션에서 재사용한다.
2. 관리자 Next.js 페이지에서 세션·권한을 검사해 로그인 이동 또는 접근 거부를 결정한다.
3. 회원 내비게이션에 관리자 전용 링크를 추가하고, 관리자 템플릿의 가짜 로그인·프로필·로그아웃을 정리한다.
4. Admin/Web 빌드·lint, 운영 권한 경계와 브라우저 화면을 확인한다. 운영에서는 Web만 교체한다.

## 범위

- 사용자별 음악 데이터나 관리자 API 상태 전이는 바꾸지 않는다.
- 관리자 목록은 서버 설정으로 유지한다. DB 역할 관리 화면과 별도 Auth0 애플리케이션은 이번 범위에 포함하지 않는다.
