# 회원 로그인 뒤 TIDAL 연결 확인

## 목표·완료 기준

- 회원 Auth0 로그인 성공 뒤 TIDAL 연결 확인 화면을 반드시 연다. 원래 요청한 회원 화면은 확인 화면의 계속 링크로 이동한다.
- 연결된 회원에게 상태와 계속 링크를 표시하고 TIDAL OAuth 재동의를 강요하지 않는다. 미연결·재연결 필요 회원에게는 연결 버튼을 표시한다.
- 관리자 화면에서 시작한 Auth0 로그인은 기존 관리자 경로로 복귀한다. 인증 오류 처리와 TIDAL OAuth 콜백은 유지한다.
- `returnTo`는 같은 사이트의 안전한 경로로 제한한다. TIDAL 연결 없이 공개 화면을 둘러보는 기존 정책은 유지한다.

## 변경 순서

1. Auth0 콜백의 회원 로그인 반환 경로를 연결 확인 화면으로 보낸다.
2. 연결 확인 화면에서 사용자별 DB 연결 상태를 표시하고 연결·계속 동작을 제공한다.
3. Web build, 변경 파일 lint, 운영 로그인 흐름·연결 상태 화면과 공개 경계를 확인한다.

## 범위

- 신규 TIDAL 권한, 자동 재인증, 플레이리스트 자동 가져오기, 데이터 모델 변경은 포함하지 않는다.
