# 비회원 재생 오류 안내 보완

## 이유와 완료 기준

- 공개 Home·EMS에서 비회원이 트랙을 선택하면 스트림 API의 `unauthorized` 코드가 플레이어 접근성 알림에 그대로 노출된다.
- 비회원에게 로그인 후 재생할 수 있다는 안내와 로그인 진입점을 제공한다.
- 내부 오류 코드가 사용자 문구로 노출되지 않도록 회귀 테스트로 고정한다.

## 변경 범위

1. `PersistentPlayer`에서 재생 오류 코드를 사용자용 한국어 문구로 변환한다.
2. `unauthorized`일 때 현재 화면으로 돌아오는 로그인 링크를 표시한다.
3. 컴포넌트 테스트, 변경 파일 lint, Web production build로 확인한다.

## 경계와 롤백

- 인증·스트림 API 계약, TIDAL 연결 상태, DB와 운영 환경은 변경하지 않는다.
- 토큰, 쿠키, Device Code, signed stream URL 등 비밀값은 코드·문서·테스트·로그에 기록하지 않는다.
- 문제가 생기면 이 작업의 플레이어 UI와 테스트 변경만 되돌린다.

## 미검증 항목

- 운영 배포와 실제 Auth0 로그인 완료 흐름은 별도 승인 전에는 실행하지 않는다.
