# 검색 완료 후 제시어 닫기 계획

## 문제

검색 API와 제시어 API를 함께 기다린 뒤 두 결과를 동시에 반영해, 카탈로그 검색이 완료된 뒤에도 제시어 목록이 결과를 가린다.

## 변경

- 제시어 응답은 검색 진행 중에 먼저 표시할 수 있게 독립 처리한다.
- 현재 요청의 카탈로그 검색이 성공하면 제시어를 즉시 비운다.
- 카탈로그 검색이 실패하면 기존처럼 제시어를 대체 탐색 경로로 유지한다.
- 새 입력, 탭 선택과 이전 요청 무효화 동작은 유지한다.

## 완료 기준

- 검색 대기 중에는 제시어가 표시될 수 있다.
- 검색 결과가 렌더링되면 제시어 listbox가 사라진다.
- 검색 실패 시 제시어와 오류 안내가 함께 유지된다.
- focused test, 전체 test, lint, build를 확인하고 커밋·푸시 후 Web만 배포한다.
