# 검색 내비게이션 위치·형태 조정

## 변경 이유

검색 메뉴가 로고 아래 독립된 입력창처럼 보여 `내 공간` 내비게이션과 시각적 위계가 끊겼다. 모바일에는 검색 진입점이 없어 화면 크기에 따라 접근성이 달라졌다.

## 변경 내용

- 데스크톱 검색을 사이드바의 일반 메뉴 리듬에 맞춘 아이콘·라벨 행으로 변경했다.
- `/search`에서 `aria-current="page"`와 보라색 active 상태를 표시한다.
- 유니코드 돋보기 문자를 일관된 SVG 아이콘으로 교체했다.
- 모바일에는 인증 컨트롤과 충돌하지 않는 상단 검색 아이콘 버튼을 추가했다.
- 포커스 링과 40px 이상 터치 영역을 유지했다.
