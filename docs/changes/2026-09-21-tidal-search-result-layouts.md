# TIDAL 검색 결과 레이아웃 변경

## 변경 이유

검색 결과를 콘텐츠 종류에 맞는 밀도로 표시하고, 별도 아티스트 결과 없이 트랙·앨범·플레이리스트 탐색에 집중하도록 구조를 정리했다.

## 변경 내용

- 검색 탭을 `통합 결과`, `트랙`, `앨범`, `플레이리스트`로 구성했다.
- `topHits`의 원래 순서를 유지하면서 아티스트 타입만 제외해 통합 결과 목록으로 정규화했다.
- 트랙은 표, 앨범과 플레이리스트는 4열 커버 그리드로 표시한다.
- 통합 결과의 트랙은 즉시 재생할 수 있고 앨범·플레이리스트는 제목과 메타데이터를 함께 표시한다.
- 검색 요청에 `topHits`, 플레이리스트 커버, 앨범 아티스트 관계를 포함했다.
