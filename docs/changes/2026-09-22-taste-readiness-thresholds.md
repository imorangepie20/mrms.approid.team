# 최초 취향 분석 시작 조건 표시

- 날짜·작업명: 2026-09-22 최초 취향 분석 시작 조건 표시
- 변경 이유: 사용자가 TIDAL 플레이리스트를 선택할 때 최초 추천에 필요한 트랙 수를 알 수 없었고, 중복 포함 저장 건수만으로 추천 준비 완료를 표시했다.
- 최종 동작:
  - 선택 화면에서 플레이리스트 곡 수 합계와 `15곡 최소`·`30곡 권장`·`60곡 다중 취향` 상태를 표시한다.
  - 선택 화면 값은 예상치임을 알리고, 가져오기 완료 후 사용자별 저장 트랙의 고유 개수로 최종 판정한다.
  - 고유 트랙이 15곡 미만이면 첫 추천 준비를 완료하지 않고 플레이리스트 추가 선택을 요청한다.
  - 완료 화면에 저장 건수와 중복 제거한 고유 트랙 수를 함께 표시한다.

  - `apps/web/src/lib/db/music-library.ts`
  - `apps/web/src/lib/tidal/client-api.ts`
