# 사용자 화면 타이포그래피·스타일 구조 정리

- 날짜·작업명: 2026-09-20 사용자 웹 화면 타이포그래피와 내비게이션 균형 조정
- 변경 이유: 전역 스타일에 동일 선택자와 모바일 규칙이 반복되어 글자 크기와 메뉴 배치가 선언 순서에 따라 달라졌고, 화면을 추가할수록 충돌 가능성이 커졌다.
- 최종 동작·관련 경로: `apps/web/src/app/globals.css`는 스타일 진입점만 담당한다. `apps/web/src/app/styles/` 아래에 토큰, 기본 스타일, 내비게이션, 대시보드, 계정, 온보딩, 반응형 규칙을 분리했다. 본문은 16px, 데스크톱 메뉴는 15px/12px, 모바일 메뉴는 12px와 44px 이상 터치 영역을 사용한다. 기존 색상과 화면 구성은 유지한다.
- 실제 검증 결과: `npm test -- --run` 19개 파일·43개 테스트 통과, `npm run lint` 통과, `npm run build` 통과. Chrome에서 기본 데스크톱 화면과 390×844 모바일 화면을 확인했다. 계산 스타일은 본문 16px, 데스크톱 메뉴 15px/12px, 사이드바 260px, 모바일 메뉴 12px이며 데스크톱 내비게이션은 모바일에서 숨김 처리됐다. Impeccable detector 결과는 경고 0건이다.
- 미검증 항목·이유: 실제 사용자 계정으로 로그인한 뒤 표시되는 모든 데이터 길이 조합은 이번 변경 범위에서 확인하지 않았다.
- 다음 작업·시작 위치: 신규 사용자 화면은 `apps/web/src/app/styles/tokens.css`의 의미 토큰을 재사용하고 기능 영역별 스타일 파일을 추가한다. TIDAL 플레이리스트 가져오기 화면에도 같은 타이포그래피 역할을 적용한다.
