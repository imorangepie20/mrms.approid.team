# 전체 플레이어 대기열 곡 정보

## 이유와 변경

- 기존 대기열은 제목과 아티스트만 표시해 곡을 구분하기 어려웠다.
- 각 곡에 앨범 아트, 앨범명, 재생 시간을 추가했다. 아트가 없거나 로드에 실패하면 음표 배경을 표시하고, 앨범·재생 시간이 없으면 해당 정보만 생략한다.
- 현재 재생곡 강조와 행 선택 동작을 유지했다. 스크린 리더는 곡 이름에 더해 아티스트·앨범·재생 시간을 설명으로 읽을 수 있다.

## 검증과 미검증

- Web production build와 TypeScript 검사 통과. `git diff --check` 통과.
- 자동 테스트는 이번 요청에서 추가·실행하지 않았다.
- 운영 적용 및 실제 브라우저 표시 확인 결과는 배포 후 기록한다.
