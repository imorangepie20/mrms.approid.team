# 사용자 대시보드 디자인 교체 완료 기록

## 변경 이유

사용자 화면을 제공된 음악 대시보드 참조의 다크 사이드바·히어로·트랙 테이블·추천 카드 구조로 통일하고, 프로젝트 브리프의 콘텐츠 밀도와 음악 이미지 활용 기준을 충족하기 위해 보완했다.

## 변경 내용

- 홈을 최신 트랙, 발견용 추천, 플랫폼 선곡, 플레이리스트의 네 컬렉션으로 확장했다.
- 참조 저장소 사용 허가 범위 안에서 사용한 Unsplash 음악 이미지를 트랙 메타데이터로 지정하고, 홈·EMS·GMS·MMS의 앨범 아트에 적용했다.
- 원격 이미지는 `next/image`와 `images.unsplash.com` 허용 설정을 사용한다.
- 온보딩을 안내 이미지, 3단계 흐름, TIDAL 연결 폼으로 구성해 대시보드 내에서 완결되도록 했다.
- 새 홈 카드의 재생 동작이 고정 플레이어로 이어지는 것을 테스트로 보장했다.

## 검증 결과

- 홈·온보딩의 새 구조에 대한 테스트를 먼저 추가하고 실패 상태를 확인한 뒤 구현했다.
- `npm run test -- src/app/page.test.tsx` 성공: 4개 테스트 통과
- `npm run test -- src/app/onboarding/page.test.tsx` 성공: 1개 테스트 통과
- 홈과 온보딩의 1440px 폭 렌더 이미지를 확인했다.

## 미검증 항목

- 실제 TIDAL 인증·권한·플레이리스트 API 호출은 구현하지 않았다.
- 참조 이미지 URL의 장기 제공 여부와 실제 음원 앨범아트 권리는 운영 단계에서 별도로 관리해야 한다.
