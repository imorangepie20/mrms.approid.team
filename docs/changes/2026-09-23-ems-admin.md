# EMS 관리자 페이지 1차

## 변경 이유

EMS 카테고리와 트랙 품질 상태를 운영자가 직접 확인하고 조정할 수 있는 같은 origin 관리자 경로가 필요했다. 기존 `hud.approid.team` 템플릿은 참고 UI 자산으로만 사용하고, 실제 주소는 `https://mrms.approid.team/admin`으로 고정했다.

## 변경 내용

- `apps/admin`에 템플릿 기반 React/Vite/Tailwind 관리자 UI를 추가했다.
- Next.js가 Vite 산출물을 `/admin`과 `/admin/*`에서 제공하도록 catch-all 셸·Docker build 단계를 추가했다.
- `ADMIN_AUTH0_SUBJECTS` 서버 allowlist를 추가하고 관리자 API에서 `401/403` 권한 경계를 적용했다.
- EMS summary, sections, tracks, ingest-runs 조회 API와 sections PATCH API를 추가했다.
- 섹션 트랙 수는 활성 트랙만 집계하고, ingest 후보·대기·모호·실패 통계를 노출한다.
- Tracks 화면에 트랙 상태 필터·cursor 페이지 이동·artwork 실패 fallback을, Sections 화면에 변경 취소를 추가했다.
- Dashboard·Sections·Tracks·Ingestion 네 화면을 실제 API와 연결했다.
- 1차 범위에는 수집 재실행·대량 삭제·DB 역할 테이블을 포함하지 않았다.
