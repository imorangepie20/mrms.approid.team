# MMS 플레이리스트 상세와 큐 재생

## 변경 이유

MMS에 가져온 플레이리스트가 카드로만 표시되어 포함 트랙을 확인하거나 플레이리스트 단위로 재생할 수 없었다.

## 변경 내용

- `user_playlist_tracks`와 저장 트랙을 사용자 소유권으로 제한해 조회하고 `position` 순서를 보존한다.
- MMS 페이지가 플레이리스트별 트랙 배열을 구성해 클라이언트에 전달한다.
- 플레이리스트 카드를 키보드로 접근 가능한 버튼으로 변경했다.
- 카드 선택 시 커버, 이름, 트랙 수, 전체 재생, 셔플과 공통 `TrackList`가 있는 인라인 상세 화면을 표시한다.
- 전체 재생과 셔플은 선택한 플레이리스트의 트랙만 `mms` 큐로 설정한다.
- 상세 화면에서 기존 MMS 라이브러리로 돌아갈 수 있다.

## 검증

- DB 사용자 범위·순서, 페이지 그룹화, 상세 전환, 전체 재생과 셔플 집중 테스트 13개 통과
- Impeccable UI 검출 결과 지적 사항 없음
- 전체 Vitest 51개 파일·181개 테스트, ESLint, production build 통과
- 새 production build로 44119 서버를 교체한 뒤 로컬·공개 `/mms`가 모두 HTTP 200을 반환했다.

## 미검증

- 실제 저장 플레이리스트 데이터가 채워진 공개 브라우저에서의 시각 확인은 최종 배포 후 수행한다.
