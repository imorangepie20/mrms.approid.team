# TIDAL 앨범·플레이리스트 상세 동작

## 목표

- 검색 결과의 앨범과 플레이리스트를 선택 가능한 항목으로 만든다.
- 선택한 컬렉션의 TIDAL 트랙을 상세 화면에서 확인하고 재생한다.
- 검색어, 탭, 결과를 유지한 채 상세 화면을 닫거나 브라우저 뒤로가기로 복귀한다.

## 변경 내용

- 통합 결과와 앨범·플레이리스트 탭의 카드를 버튼으로 변경했다.
- 상세 화면에 커버, 제목, 아티스트·큐레이터, 트랙 수, 전체 재생, 셔플, 공통 트랙 목록을 추가했다.
- 로딩 skeleton, 재시도 가능한 오류 상태, 빈 트랙 상태를 추가했다.
- `/api/tidal/catalog`이 앨범·플레이리스트 트랙을 TIDAL JSON:API에서 조회해 재생 가능한 트랙으로 정규화한다.
- 20곡을 넘는 플레이리스트의 TIDAL 상대 cursor를 API base path에 안전하게 결합한다.

## 검증 결과

- `npm test`: 44개 파일, 140개 테스트 통과.
- `npm run lint`: 통과.
- `npm run build`: 통과.
- Impeccable detector: 지적 사항 없음.
- 공개 도메인에서 `Random Access Memories` 앨범 13곡을 확인했다.
- 공개 도메인에서 `Daft Punk Essentials` 플레이리스트 25곡과 전체 재생·셔플 활성화를 확인했다.
- 브라우저 뒤로가기가 `Daft Punk` 검색어와 선택 탭·결과를 유지하는 것을 확인했다.
- 390×844 viewport에서 상세 커버, 메타데이터, 재생 버튼, 트랙 테이블을 확인했다.

## 미검증 항목

- 실제 전체 재생·셔플은 소리가 날 수 있어 브라우저에서 실행하지 않았다. 큐 설정은 컴포넌트 테스트로 검증했다.
