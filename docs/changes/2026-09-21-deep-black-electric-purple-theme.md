# 딥 블랙·전기 보라 테마 조정

## 변경 이유

기존 화면의 청록 포인트와 흰색 검색 카드가 어두운 음악 앱 표면과 분리되어 보였다. 전체 화면을 딥 블랙 기반으로 통일하고 주요 행동을 전기 보라로 명확히 표시하도록 조정했다.

## 변경 내용

- 공통 색상 토큰을 딥 블랙, 어두운 카드 표면, 전기 보라, 네온 마젠타 팔레트로 변경했다.
- 사이드바, 대시보드, 온보딩의 청록·기존 보라 하드코딩 값을 새 토큰에 맞췄다.
- 검색 입력, 추천 목록, 트랙·앨범·아티스트 카드를 어두운 표면으로 통일했다.
- 재생·저장·연결 버튼과 포커스 링을 공통 강조색으로 통일했다.
- 검색 제목을 `600` 굵기와 절제된 크기로 낮추고 불필요한 상단 라벨을 제거했다.
- 카드 하단의 큰 재생 버튼을 앨범 이미지 위 36px 원형 SVG 버튼으로 바꾸고 장식 오버레이와 강한 그림자를 제거했다.
- 데스크톱에서는 앨범 이미지 호버·키보드 포커스 시 45% 검정 오버레이와 중앙 재생 버튼을 표시하고, 터치 기기에서는 버튼을 항상 노출한다.
- 중앙 재생 버튼은 진한 반투명 보라 배경과 흰색 아이콘을 사용하며, 호버 시 더 선명한 반투명 보라로 전환한다.
- 중앙 재생 버튼에 `rgba(46, 16, 101, 0.95)`의 어두운 보라색 1px 테두리를 추가했다.
- 모바일 고정 계정 컨트롤과 검색 제목 사이에 16px 간격을 확보했다.
- 검색 결과가 존재하면 검색어 추천 목록을 닫고, 결과가 비어 있을 때만 대체 검색어를 유지한다.
- 검색 결과 컨테이너와 하단 고정 플레이어의 `max-width` 제한을 제거해 모든 페이지가 사이드바를 제외한 가용 폭을 사용하도록 정리했다. 제목·검색 입력처럼 읽기 폭이 중요한 요소의 제한은 유지했다.
- 일반 텍스트 대비는 WCAG AA 이상이 되도록 확인했다. `#9B5CFF` 버튼에는 딥 블랙 글자를 사용해 대비를 `4.81:1`로 확보했다.

## 검증 결과

- 관련 컴포넌트 및 검색 테스트: 4개 파일, 10개 테스트 통과
- `npm run lint`: 성공
- `npm run build`: 성공
- Playwright 공개 도메인 검증: 홈·검색 렌더링, 검색 API `200`, 카드 20개, 실패 요청 0건
- Playwright 데스크톱·모바일 검증: 제목 `30px/600`, 재생 버튼 `36px`, 모바일 가로 넘침 없음
- Playwright 실제 검색 검증: 결과 20개 표시 후 추천 `listbox` 0개
- Playwright 호버 검증: 오버레이 투명도 `0 → 1`, 배경 `45%` 검정, 버튼 중심 오차 `0px`
- Playwright 테두리 검증: 계산된 그림자에 `rgba(46, 16, 101, 0.95) 0 0 0 1px` 적용
- 가로폭 변경 관련 컴포넌트 테스트: 2개 파일, 4개 테스트 통과
- 1920px Playwright 검증: 검색 결과 구분선과 하단 플레이어가 콘텐츠 영역 전체 폭을 사용함
- Impeccable 레이아웃 detector: 지적 사항 없음
- 계산된 주요 대비: 본문/배경 `18.64:1`, 보조 텍스트/카드 `8.84:1`, 버튼 글자/강조색 `4.81:1`

## 미검증 항목

- 실제 모바일 기기의 색 재현과 고대비 모드는 확인하지 않았다.
