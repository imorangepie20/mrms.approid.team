# 전체 플레이어 화면 개선

## 이유

기존 전체 플레이어는 큰 앨범 아트 아래에 현재 곡 정보와 조작부가 일렬로 이어졌다. 작은 화면에서는 곡 제목이 아래로 밀리고, 대기열도 본문과 구분이 약했다.

## 변경

- 전체 플레이어를 앨범 아트와 현재 곡·조작부의 2열로 구성했다. 모바일에서는 아트 크기를 화면 높이에 맞게 줄이고 한 열로 배치한다.
- 제목·아티스트·앨범·재생 상태·대기열 위치를 현재 곡 카드에 표시한다.
- 아트, 현재 곡, 대기열에 구분된 표면을 적용하고 현재 곡의 대기열 행을 강조한다.
- 기존 좋아요·탐색·재생·셔플·반복·볼륨 조작과 접근성 이름은 유지했다. 재생 엔진과 API는 변경하지 않았다.

## 검증

- Web production build와 변경 파일 ESLint 통과. 로컬 build의 Auth0 환경 변수 경고는 기존과 같다.
- Impeccable `detect` 지적 0건, `git diff --check` 통과.
- 자동 테스트는 요청되지 않아 추가하거나 실행하지 않았다.

## 운영 적용·미검증

- `9884548`을 Zorin Web 이미지로 빌드하고 Web 컨테이너만 교체했다. 이전 이미지는 `music-pie-web:pre-full-player-20260925`로 보존했다. Web은 healthy, 공개 readiness는 HTTP 200이다.
- 공개 Home에서 실제 곡을 재생하고 전체 플레이어를 열었다. 현재 곡 제목·아티스트·앨범·재생 상태·재생 위치·대기열 강조가 표시됐다. 데스크톱과 390×844 모바일에서 박스 배치와 첫 화면의 현재 곡 정보 표시를 확인했다.
- 검증 재생은 일시 정지하고 전체 플레이어를 닫았다. 자동 테스트는 요청되지 않아 실행하지 않았다.
