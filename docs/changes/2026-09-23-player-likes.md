# 플레이어 좋아요

## 변경 이유

재생 중인 트랙을 다른 화면으로 이동하지 않고도 좋아요로 저장할 수 있어야 한다. 기존 좋아요 저장·낙관적 상태 갱신 흐름을 플레이어에서도 사용하도록 연결한다.

## 변경 내용

- 전역 하단 플레이어에 현재 트랙용 좋아요 버튼을 추가했다.
- 전체 화면 플레이어의 곡 제목·아티스트 아래에 같은 좋아요 버튼을 추가했다.
- 전체 화면 플레이어의 커버 영역에 현재 트랙 앨범 이미지를 표시하고, 이미지 로드 실패 시 기존 그라데이션 fallback을 유지한다.
- 두 위치 모두 `trackLikeItem`과 `LikeButton`을 사용해 TIDAL·카탈로그 트랙, 인증 리다이렉트, 저장 실패 복구를 기존 규칙과 일치시켰다.
- 컴팩트·전체 화면 플레이어에서 좋아요 상태가 동기화되는 회귀 테스트를 추가했다.

## 검증 결과

- 플레이어 focused Vitest 8개 통과
- 전체 Vitest 84개 파일·345개 테스트 통과
- lint 오류 0(기존 경고 3), Next.js build·TypeScript 통과

## 미검증 항목

- 로그인된 실제 브라우저에서 좋아요 저장 후 MMS 즉시 반영되는 시각 확인은 배포 후 수행한다.
