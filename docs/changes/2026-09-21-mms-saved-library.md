# MMS 저장 라이브러리 연결

## 목표

- 플레이리스트 가져오기로 저장한 트랙을 MMS에 표시한다.
- MMS 재생 목록에 TIDAL 트랙 식별자와 재생 시간을 전달한다.
- TIDAL 연결을 해제해도 로그인한 사용자의 저장 음악은 계속 표시한다.

## 구현 계획

1. Auth0 사용자 범위로 저장 트랙을 조회하는 repository 함수를 추가한다.
2. MMS 서버 페이지에서 연결 상태와 저장 트랙을 함께 조회한다.
3. `MusicDashboard`가 MMS에서 fixture 대신 전달받은 트랙을 사용하게 한다.
4. repository, 페이지 전달, 연결 해제 상태 렌더링을 회귀 테스트한다.

## 완료 기준

- 다른 사용자의 트랙이 섞이지 않는다.
- 저장 트랙의 커버, 제목, 아티스트, 앨범, 길이가 트랙 목록에 표시된다.
- 저장 트랙을 누르면 기존 TIDAL 플레이어 큐로 재생을 요청한다.
- 연결 해제 상태에서도 저장 트랙을 볼 수 있다.

## 검증 결과

- 저장 트랙 repository가 Auth0 subject로 사용자를 격리하고 TIDAL 재생 필드를 반환한다.
- MMS는 DB의 플레이리스트·트랙을 표시하며 fixture를 사용하지 않는다.
- 내 음악 요약, 전체 재생, 셔플, 플레이리스트 4열 그리드, 트랙 검색·정렬, 빈 상태를 추가했다.
- TIDAL 연결 해제 상태에서도 저장 음악을 표시하고 재연결 안내만 제공한다.
- 실제 PostgreSQL에서 기존 사용자 1명과 연결 1건을 보존한 채 `002_tidal_connection_runtime.sql`, `003_user_music_library.sql`을 적용했다.
- `npm test`: 43개 파일, 132개 테스트 통과.
- `npm run lint`: 통과.
- `npm run build`: 통과.
- 브라우저에서 `https://mrms.approid.team/mms` 데스크톱·390×844 모바일 빈 상태를 확인했다.

## 미검증 항목

- 실제 플레이리스트를 새로 가져온 뒤 데이터가 채워진 MMS의 브라우저 시각 검증은 하지 않았다.
- 실제 MMS 트랙 재생은 소리가 날 수 있어 이번 검증에서 실행하지 않았다.
