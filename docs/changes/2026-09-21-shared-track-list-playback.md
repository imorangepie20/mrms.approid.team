# 공통 트랙 목록과 재생

## 변경 이유

검색·EMS·MMS가 서로 다른 트랙 행을 사용해 재생 큐 동작과 화면 구조가 일관되지 않았다.

## 변경 내용

- 공통 `TrackList` 컴포넌트를 추가했다.
- 트랙 번호, 커버, 제목, 아티스트, 앨범, 재생 시간과 재생 버튼을 같은 표 구조로 표시한다.
- 트랙 선택 시 현재 목록 전체를 전역 큐로 설정하고 선택한 트랙을 즉시 재생한다.
- 검색 트랙 탭, EMS, MMS가 공통 컴포넌트를 사용하도록 변경했다.
- GMS 선호 액션 카드는 기존 동작을 유지했다.
- 사용하지 않게 된 기존 `.track-table`, `.track-row`, `.cover` 스타일을 제거했다.
- 전역 플레이어와 전체 플레이어에 셔플, 전체/한 곡 반복, 이전/다음 경계 처리, 볼륨, 음소거와 재생 시간을 추가했다.
- 셔플은 재생 중인 곡을 첫 항목으로 유지하고 나머지 대기열만 무작위로 정렬한다.
- 전체 플레이어의 대기열에서 현재 곡을 강조하고 `aria-current`로 표시한다.
- 하단 전역 플레이어 썸네일은 현재 트랙의 실제 `artworkUrl`을 표시하고, 이미지가 없거나 로드에 실패하면 기존 그라데이션을 유지한다.
- 트랙 썸네일에 마우스를 올리거나 키보드로 재생 버튼에 초점을 두면 중앙 재생 아이콘을 표시한다.
- 공통 트랙 목록은 `tidalTrackId`를 우선해 현재 트랙을 판별하고, 재생 중인 행의 번호를 음량 막대 아이콘으로 바꾸며 행 배경과 제목을 강조한다. 일시 정지 상태에서도 현재 트랙 표시를 유지하고 일시 정지 아이콘과 접근성 문구를 제공한다.
- 검색 응답의 `attributes.availability`에 `STREAM`이 없는 트랙은 목록에서 흐리게 표시하고 재생 버튼을 비활성화한다. 이 트랙은 전체 재생·셔플 큐에서도 제외하며 대체 트랙을 임의로 조회하지 않는다.
- TIDAL DASH manifest를 네이티브 미디어 요소에 전달하던 `browser` 플레이어 강제를 제거하고 `shaka` 플레이어를 사용한다.

## 검증 결과

- 수정 전 공통 컴포넌트 모듈이 없어 회귀 테스트가 실패하는 것을 확인했다.
- 공통 컴포넌트·검색 테스트: 4개 통과
- 전체 테스트: 129개 통과
- ESLint: 통과
- production build: 통과
- 공개 도메인 실제 검색에서 트랙 표와 72개 결과를 확인했다.
- `One More Time` 선택 후 전역 플레이어에 곡·아티스트·컨트롤이 표시되고, 다음 트랙이 `Around the World`로 전환되는 것을 확인했다.
- 공개 도메인에서 셔플 활성 상태와 전체 플레이어의 현재 곡 강조를 확인했다.
- 데스크톱과 모바일 공개 화면에서 썸네일 재생 오버레이를 확인했다.
- 공개 도메인에서 `One More Time` 재생 시간이 증가하고, 미디어 요소가 `paused: false`, `readyState: 4`, 오류 없음 상태인 것을 확인했다.
- 전역 플레이어 썸네일 집중 테스트 6개와 전체 Vitest 50개 파일·170개 테스트, ESLint, production build를 통과했다. Impeccable UI 검출 결과는 지적 사항 없음이었다.
- 현재 트랙 표시 집중 테스트 5개와 전체 Vitest 50개 파일·172개 테스트, ESLint, production build를 통과했다. Impeccable UI 검출 결과는 지적 사항 없음이었다.
- TIDAL 재생 가능 여부 매핑, 비활성 버튼, 큐 제외 집중 테스트 22개를 통과했다.
- 최종 전체 Vitest 50개 파일·176개 테스트, ESLint, production build, `git diff --check`를 통과했다. Impeccable UI 검출 결과는 지적 사항 없음이었다.
- 새 production build로 44119 서버를 교체한 뒤 로컬·공개 `/search`가 모두 HTTP 200을 반환했다.

## 미검증·제약

- fixture 기반 EMS·MMS 트랙에는 `tidalTrackId`가 없어 실제 TIDAL 스트리밍 대상이 아니다.

## 다음 작업

- 실제 브라우저·모바일 기기에서 TIDAL 오디오 스트림 재생을 확인한다.
- EMS·MMS를 저장된 TIDAL 트랙 데이터로 교체하면 동일 `TrackList`에서 실재생한다.
