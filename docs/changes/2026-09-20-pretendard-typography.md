# Pretendard Variable 타이포그래피 적용 기록

## 변경 이유

사용자 대시보드의 한글과 영문 표기가 서로 다른 시스템 폰트에 의존하고 있었고, 제목·본문·메타 정보의 크기 기준도 일관되지 않았다. 사용자 요청에 따라 `Pretendard Variable`을 전역 글꼴로 적용하고 화면 밀도에 맞는 크기 체계를 정리했다.

## 변경 내용

- `apps/web`에 `pretendard@1.3.9` 의존성을 추가하고 Variable CSS를 전역으로 불러왔다.
- 기존 Geist 로딩을 제거하고 본문 전역 글꼴을 `Pretendard Variable`로 지정했다.
- 페이지 제목 24px, 섹션 제목 22px, 트랙 제목 15px, 본문 14px, 메타 정보 12~13px을 기준으로 데스크톱 크기를 조정했다.
- 모바일에서는 페이지 제목 20px, 히어로 제목 31px, 섹션 제목 19px으로 축소했다.
- 모바일 하단 메뉴를 4열 독립 구조로 분리해 각 공간(MAIN, MMS, GMS, EMS)이 같은 폭을 사용하도록 했다.

## 검증 결과

- `npm run test` 성공: 8개 테스트 파일, 16개 테스트 통과
- `npm run lint` 성공
- `npm run build` 성공 (변경 전 폰트 적용 직후)
- `http://localhost:43817/ems` 응답 상태 `200` 확인
- 390px 폭 EMS 화면에서 Pretendard 적용과 트랙 정보 크기를 확인했다.

## 미검증 항목

- 실제 TIDAL 인증·플레이리스트 연동은 이 UI 변경 범위에 포함하지 않았다.
- 실제 사용자 기기와 브라우저별 폰트 렌더링은 별도 QA가 필요하다.
